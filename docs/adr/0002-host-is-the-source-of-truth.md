# The host is the source of truth, not the chats

The Playbook is first filled from exported Claude chats, but those chats are full of abandoned attempts and suggestions that were never applied. So the live host is the source of truth: anything taken from a chat is marked unverified until it has been checked against the host, and verifying it is a separate later pass. Writing confidently from chats alone would give us a Playbook that describes a homelab that never existed.
